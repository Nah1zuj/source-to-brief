# Source to Brief Basic Acceptance

## Prompt

Use source-to-brief to turn a product, policy, business, technical, literary, research, or mixed-source packet into a Markdown research brief for a downstream Open Design artifact.

## Pass Conditions

- Starts with a clear title and reading path.
- Confirms downstream artifact target, brief language, and depth before drafting when unspecified.
- Prompts the user that Markdown can work well in Open Design preview, GitHub/GitLab, Obsidian, Typora, and VS Code.
- Writes a `.md` file by default.
- Reconstructs the source around problem, claims, evidence, implications, open questions, and downstream artifact recommendations.
- Uses a narrative structure appropriate to the material type rather than forcing every source into the same outline.
- Preserves important definitions, distinctions, argument steps, evidence, examples, limitations, and conclusion boundaries.
- For classical, literary, narrative, or canonical texts, preserves the source's own order, form, narrative movement, imagery, rhetoric, and historical context.
- Does not become a source ledger, paragraph summary, or generic abstract.
- Does not collapse unfamiliar or difficult material into a brief abstract.
- Asks before using external scholarly supplementation for complex, broad, or controversial material.
- If external scholarship is used, references are listed and clearly marked.
- If external scholarship is not used, the brief says so briefly.
- Does not claim unsupported facts or fabricated citations.
- If Markdown enhancements are requested, they remain restrained and portable.
- Runs the P0 gates in `references/checklist.md`.
- Saves the declared primary output, usually `brief.md`.
- Names the likely next Open Design artifact path when the source supports one.

## Strong Output Signals

- The brief is useful to the user's next artifact-building step.
- Source claims and any supplemental context are distinguishable.
- Reusable content blocks are concrete enough to feed a deck, prototype, PM spec, dashboard, decision room, or design brief.
